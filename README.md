# Pixel Clone

A simple tool to generate AI images, inspired by the discontinued Pixel Studio app.

## Features
- **Projects**: Keep your images organized.
- **AI Generation**: Create art using Google Gemini.
- **History**: View and manage past generations.
- **Sharing**: Export your work easily.

---

## Using Your Own API Key
Pixel Clone uses a "Bring Your Own Key" model. You'll need a free Google AI API key to generate images.

### 1. Get Your Key
1. Visit [Google AI Studio](https://aistudio.google.com/).
2. Sign in and click **Get API key** in the sidebar.
3. Click **Create API key** and **copy** it. Keep this key private.

### 2. Add Key to App
1. Open Pixel Clone and go to **Settings** (found in the top-left menu).
2. **Paste** your key into the **API Key** field.
3. Click **Save**.

### 3. Start Generating
Navigate to a project and try creating an image to verify it works!

---
*Note: AI generation is subject to Google's rate limits. See the [Google AI documentation](https://ai.google.dev/docs) for more info.*
